# Modern card-based UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle every page of geltech.dev in the approved card-based look (direction B) and add a light/dark switch that defaults to the device setting.

**Architecture:** Plain CSS rewrite of `src/styles/global.css` on new tokens; small Astro components for the top bar, theme switch, post card and project card; one inline `<head>` script (`id="theme-init"`) for the theme. Two pure, tested helpers: reading time and the build check's script allowance.

**Tech Stack:** Astro 7.4.13 (static), TypeScript strict, plain CSS, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-21-modern-ui-design.md` (approved 2026-11-21). Project rules: `CLAUDE.md`, `docs/SPEC.md`.

## Global Constraints

- Node 24 (`export PATH=$HOME/.nvm/versions/node/v24.22.3/bin:$PATH` in every shell).
- No new dependencies. No web font, CSS framework, icon library or UI kit. System font stack (`--font`) only.
- No third-party requests. Icons are inline SVG.
- Client JS: only the theme script (every page) and the existing CV tabs script (`/about/`). Nothing else.
- Identity only from `src/site.config.ts`. Brand text is `new URL(site.url).host` ("geltech.dev"), never hard-coded.
- Never name an employer outside the CV body on `/about/`.
- Images via `astro:assets` with width and height.
- WCAG 2.2 AA in both themes: text 4.5:1, large text and UI parts 3:1. `--muted` must pass on both `--bg` and `--surface`.
- Post body reading width ~70ch. Grids only on list pages.
- All transitions off under `prefers-reduced-motion: reduce`.
- Branch `feat/modern-ui` off `main` (the spec commit on `chore/modern-ui-design` comes along: branch from it). Conventional Commits. Never push to `main`.
- Done = `npm test`, `npm run check`, `SITE_STRICT=1 npm run build`, `npm run verify` all pass.

Radius 12px cards, 999px pills, 8px buttons. Keep `--code-bg`, spacing `--s1…--s5`, `--font`, `--mono`.

## Review Focus

1. **Storage blocked** (Safari private mode, cookies off): `localStorage` throws. Expected: the page still follows the device theme and the switch still flips the theme for that page view, with no console error. → Task 3, Step 5 check.
2. **JS off:** the switch is invisible (`visibility: hidden`, space kept), the page follows the device theme, nothing shifts. → Task 3, Step 5 check.
3. **Device theme changes while the page is open, no saved choice:** colours follow live (pure CSS) and the switch's label stays correct (`matchMedia` change listener). → Task 3, Step 5 check.
4. **Sticky top bar hides anchor targets:** `/about/#cv-speaking`, heading links and the skip link land under the bar. Expected: `scroll-margin-top` on `:target`/headings at least the bar height (two rows on phones). → Task 3 CSS + Task 6 check.
5. **360px phone with long content:** a long post title, an unbroken tag or URL, or the four nav pills must not cause horizontal scroll. Expected: `overflow-wrap: anywhere` on card titles/tags, pills share the row. → Task 3 and Task 4 checks.

**Interfaces:**

- Produces for later tasks, CSS classes: `.container` (max ~1100px, side padding), `.card` (surface, border, 12px radius, light shadow), `.card-grid` (`grid-template-columns: repeat(auto-fill, minmax(min(280px, 100%), 1fr))`), `.btn`, `.btn-primary`, `.btn-secondary`, `.pill` (999px), `.chip` (tag label), `.badge` + `.badge-live|beta|archived`, `.muted`, `.section-label` (small uppercase heading style for h2s like "Latest writing"), `.prose` (reading column ≤70ch, body typography).

- [ ] **Step 1: Write `ThemeScript.astro`**: `<script is:inline id="theme-init">` (is:inline so Astro doesn't bundle it into a module). Behaviour, in order:
  1. `try { t = localStorage.getItem('theme') } catch {}`; if `t` is `light` or `dark`, set `document.documentElement.dataset.theme = t`.
  2. `document.documentElement.dataset.js = ''`.
  3. `effective()` = `dataset.theme` else `matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'`.
  4. `label()` sets every `[data-theme-toggle]`'s `aria-label` to `Switch to dark theme` / `Switch to light theme` (the opposite of `effective()`). Run on `DOMContentLoaded` and on the media query's `change` event.
  5. Delegated `click` on `document`: if `e.target.closest('[data-theme-toggle]')`, flip `effective()`, set `dataset.theme`, `try { localStorage.setItem('theme', next) } catch {}`, `label()`.

- [ ] **Step 2: Write `ThemeToggle.astro`**: the button with `aria-label="Switch theme"` default, a moon SVG (`class="icon-moon"`) and a sun SVG (`class="icon-sun"`), both `aria-hidden="true"`, 20px, `stroke="currentColor"`. CSS shows the moon when the effective theme is light, the sun when dark (same two selectors as the tokens).

- [ ] **Step 3: Rewrite `global.css` tokens and shared pieces**:
  - Light tokens on `:root` with `color-scheme: light`. Dark tokens in `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … color-scheme: dark } }` **and** `:root[data-theme="dark"] { … }`. Same two selectors for the Shiki override (`--shiki-dark`, `--shiki-dark-bg`) that exists today.
  - `.theme-toggle { visibility: hidden }`, `[data-js] .theme-toggle { visibility: visible }`.
  - Top bar `.site-header`: `position: sticky; top: 0; z-index: 10`; background `--surface` solid, then `@supports (backdrop-filter: blur(8px))` a translucent `--surface` (`color-mix(in srgb, var(--surface) 85%, transparent)`) with blur; bottom border. Inside `.container`: brand (`.logo` 22px gradient square `#2563eb → #7c3aed`, `aria-hidden`; text = host of `site.url`), nav, switch. Below 640px: `flex-wrap: wrap`, nav `order: 3; flex-basis: 100%`, pills `flex: 1` and centred.
  - Nav pill group: `--bg` track, links as `.pill`; `[aria-current="page"]` gets `--surface` fill, `--fg`, 600 weight, small shadow. Visible `:focus-visible` outline (2px `--accent`, offset 2px) on all links, buttons, tabs.
  - `html { scroll-padding-top: 5rem }` and a phones value of `7rem` (covers the two-row bar; Review Focus 4).
  - Card hover lift (`translateY(-1px)`, larger shadow) only on `.card:has(a.stretched)`; in dark, cards use the border only, no shadow.
  - `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { transition: none !important; animation: none !important } }`.
  - Remove CSS for classes no longer used after Tasks 4–7 in those tasks, not here.
