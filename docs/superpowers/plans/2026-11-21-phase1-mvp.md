# geltech.dev Phase 1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the static geltech.dev MVP (home, blog, post, About with CV, Projects with Dishkept, RSS, sitemap) deployable to Cloudflare Workers Static Assets via GitHub Actions.

**Architecture:** Astro static build with three content collections (`blog`, `projects`, `pages`). Pure TS helpers (draft filter, config guard, slugify, dist verifier) are kept free of `astro:*` imports so they're unit-testable with `node:test`. One `BaseHead` owns all meta; one global stylesheet; zero client JS.

**Tech Stack:** Node 24 LTS (native TS type stripping), Astro 7.x, `@astrojs/rss`, `@astrojs/sitemap`, `@astrojs/check` + `typescript`, `wrangler` 4.x (CI only), `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-21-phase1-mvp-design.md` (design) and `docs/SPEC.md` (product spec, v0.4 after Task 1). Read both.

## Global Constraints

- `output: 'static'`, no adapter, no server code. Plain CSS, no framework. npm only; **pin exact versions** (`npm i -E`). No dependency beyond those in Tech Stack without asking.
- **Node ≥ 22.23.4 required by Astro 7.** The author's machine has Node 20; Task 2 adds `.nvmrc` = `24` and README notes `nvm use`.
- Zero client JS in Phase 1. The only `<script>` allowed in `dist/` is `type="application/ld+json"`.
- No third-party requests on page load. Share links are plain `<a>` tags.
- Identity (name, tagline, bio, links, url) comes only from `src/site.config.ts`.
- No employer name anywhere except the CV section of `/about/` (rendered from `src/content/pages/cv.md`). `/about/`'s meta description, OG tags and JSON-LD stay generic; never emit `worksFor`.
- `draft: true` posts never reach production pages, RSS or sitemap; they render in `npm run dev`.
- Never run `wrangler deploy` locally; never touch DNS or Cloudflare settings.
- WCAG 2.2 AA: semantic landmarks, visible `:focus-visible`, AA contrast in light and dark.
- Conventional Commits; commit message trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. One branch + PR per task (`chore/…`, `feat/…`); never push to `main`.
- Every task ends with `npm run check`, `npm test` and `npm run build` passing with no new warnings (from Task 2 on).

## Review Focus

1. **Odd post titles** (quotes, `&`, emoji, accented letters, all punctuation): `new-post` must yield a clean ASCII slug or refuse with an error when the slug would be empty; titles must be HTML-escaped in `<title>` and OG tags. Tests in Task 6 and Task 3.
2. **Invalid frontmatter** (missing `description`, `description` > 160 chars, bad date): the build must fail naming the file and field (§8). Verification step in Task 3.
3. **Only drafts exist (launch state):** home and `/blog/` show "No posts yet.", `rss.xml` is valid with zero items, no `/blog/hello-world/` in `dist/`. Covered by `verify-dist` in Task 5.
4. **Long unbroken content on a phone** (a 200-char URL in a paragraph, a wide code block, a wide table): no horizontal page scroll at 360px. Verification step in Task 2 (CSS) re-run in Task 4.
5. **Employer names leaking outside the CV**: no company name from `cv.md` role headings appears in any `dist/` file except `about/index.html`, and inside that file not in `<head>`. Check in `verify-dist`, Task 5.
